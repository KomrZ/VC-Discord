    Текстовый канал: музыка и общение

    Текстовый канал выключен

    Команда «Астра, выйди из канала» работает голосом и текстом; в тексте также есть !leave. Запрашивающий должен находиться в том же голосовом канале, что и бот. Публичные команды и таймер действуют только на сеансы по призыву: ручное подключение владельца и смены радиоведущей защищены. Таймер сбрасывается, если вернулся хотя бы один человек; другие боты слушателями не считаются. При слушателях отсутствие новых заказов не отключает музыку. Текстовый чат после выхода остаётся доступным.

    Смена не прерывает ручное подключение владельца или другой эфир. При выключенном приоритете занятый бот отклонит начало смены; таймер не повторяет пропущенный запуск. Во время смены публичные призывы не уводят бота в другой канал, а музыкальные заказы не меняют программу. Поиск песен и текстовый чат продолжают работать. После окончания смены бот выходит из голосового канала; текстовый канал остаётся подключённым.

    В Developer Portal → Bot включите Message Content Intent. В текстовом канале выдайте боту View Channel, Send Messages и Read Message History. Для призыва нужны Connect и Speak в голосовом канале участника. Запятая после «Астра» необязательна. Занятый бот не переходит в другой канал.

    Примеры: «Астра включи песню Кино — Звезда по имени Солнце», !find название, !play 2, !wave yandex, !wave spotify, !playlist ссылка. Поддерживаются ссылки на доступные плейлисты VK, Яндекс Музыки и Spotify любого владельца. Сохранять их в свою медиатеку не нужно. Новый заказ включает выбранную музыку сразу.

    Для начала диалога обратитесь к Астре по имени или ответьте на её сообщение. Затем она оценивает новые сообщения вместе с контекстом в течение указанного времени и может пропускать разговор участников между собой. Память хранит последние 60 сообщений отдельно от голоса и личного чата Astra; выбранная модель получает до 24 последних сообщений общего канала. Память сохраняется при перезапуске.

    Как начинается разговор

    Распознавание речи

    Поддерживаются Whisper и Web Speech-to-Text. Для перехода на Google требуется разрешить отправку речи ниже.

    Использует уже скачанную модель Whisper из Astra. Речь обрабатывается на этом ПК в отдельном процессе и не сохраняется в файлы. Большая модель точнее, но требует больше памяти и времени.

    Установит движок в отдельное окружение плагина. Уже скачанная модель Astra используется без повторной загрузки.

    Распознаёт звук из Discord через Google, как Web Speech-to-Text в Astra. Нужен интернет; общий бесплатный доступ может быть ограничен Google. Используется отдельное подключение без управления плагином Web STT.

    Поддерживается OpenAI-совместимый адрес /audio/transcriptions. При облачном API речь отправляется выбранному сервису.

    Речь распознаётся на вашем ПК. Нужен Python с пакетом vosk и распакованная русская модель.

    Создаст отдельное окружение и скачает небольшую русскую модель, около 45 МБ.

    Личность Astra

    Берёт текущее описание личности Astra перед каждой репликой. Изменения характера подхватываются автоматически. Если описание пустое, используется обычный характер бота.

    Модель для общего разговора

    Модель получает общий разговор. При включённом показе экрана она также получает выбранные снимки. Можно использовать локальную модель в LM Studio.

    Берёт текущие модель и адрес выбранного подключения Astra перед каждой новой репликой. Для каждого провайдера используется его сохранённый ключ из плагина. Личная история и инструменты Astra в общий разговор не передаются. Для ручного выбора выключите эту настройку. Для облачной модели отдельно разрешите отправку снимков во вкладке «Экран». Рекомендуется локальная модель.

    Голос ответов

    Использует скачанную модель Astra, выбранный голос и скорость. Звук направляется в Discord.

    Проверяем выбранный Python, активное окружение, PATH и типичные папки окружений. Подготовка устанавливает пакеты в папку данных пользователя; модель скачайте в Astra.

    Выберите JSON-файл голоса Supertonic

    Vox пока не может передавать звук в Discord: API Astra озвучивает только на ПК. Лицензия Astra не разрешает включать её движок в сторонний плагин без разрешения автора. Доступны Supertonic, системный голос и облачные сервисы.

    Провайдер должен поддерживать /audio/speech и выдавать PCM 24 кГц.

    Fish Audio

    Текст ответов отправляется в Fish Audio. Плагин использует официальный сервер api.fish.audio; ключ хранится отдельно от других сервисов.

    По умолчанию выбрана s2.1-pro-free. Доступность и тариф проверяйте в аккаунте Fish Audio; остальные модели могут быть платными. Адрес /v1/tts и формат звука плагин настроит сам.

    Астра видит твой экран

    Пока показ включён, к каждой реплике разрешённого аккаунта добавляется свежий снимок выбранного экрана. Ответ слышат все участники канала.

    Рекомендуется локальная модель в LM Studio: снимки остаются на вашем ПК. Можно выбрать облачную модель с поддержкой изображений и OpenAI-совместимым Chat Completions API во вкладке «Голос и модель». В облаке снимки передаются провайдеру и запросы могут быть платными.

Снимок прикладывается только к репликам аккаунтов из списка ниже; у кого здесь нет Discord ID, снимок не передаётся.

    Оставь вкладку выбора экрана в браузере открытой. Плагин хранит последний кадр только в памяти этого ПК. Показ выключается при закрытии вкладки, отключении бота, смене модели или разрешений и перезапуске плагина. После этого экран нужно выбрать заново. Нажатие «Остановить показ экрана» отменяет текущий ответ; уже отправленный запрос мог быть обработан моделью.

    Astra — радиоведущая

    Боты не считаются слушателями. Музыка продолжает играть; модель и озвучка для подводок не вызываются.

    Уведомление отправляется после запуска музыки в выбранный канал из вкладки «Подключение». Текстовый канал должен быть включён; разрешать ИИ-чат для уведомлений не требуется. Время указано по Екатеринбургу (UTC+5).

    Смены задаются во вкладке «Радио» таймера: дни, время начала и конца, канал и музыка. На время смены подводки включаются автоматически; ваши обычные настройки сохраняются. Astra и три плагина должны работать.

    В конце песни — за 30 секунд до завершения. Если длительность неизвестна, подводка прозвучит в начале.

    Личность, модель и голос берутся из вкладки «Голос и модель». Astra представляет начавшуюся песню и иногда добавляет короткий рассказ об исполнителе. Музыка на время речи становится тише; разговоры участников имеют приоритет. Сохраните настройки, чтобы применить изменения.

    Найти и включить трек

    Плейлисты

    Spotify доступен при включённом режиме без окна браузера в Astra Music. Во время трансляции Spotify звучит только в Discord; остановка трансляции ставит Spotify на паузу. Песня и переключение общие с виджетом Astra. Пауза и громкость Discord регулируются отдельно.

    Astra Music должна быть включена. Голосовое управление доступно аккаунтам из списка «Доступ к ПК»: «Астра, включи песню …», «Астра, включи плейлист …», «Астра, включи мою волну», «Астра, громкость 5», «Астра, музыку тише», «Астра, следующий трек».

    Голосовое управление участниками

    Перемещение, серверный мут микрофона и звука, отключение от голосового канала и исключение с сервера. Выбирать можно людей в канале бота.

    Если выключить, команды выполняются сразу для однозначно выбранного участника и канала. При неизвестном или неоднозначном имени бот попросит выбрать номер; после выбора действие выполнится сразу. Доступ по Discord ID и проверка прав сохраняются.

    Этот список независим от доступа к ПК. Нажатие кнопки копирует ID; проверьте их и сохраните настройки.

    Как выбрать правильного человека

    Каждому участнику назначен номер, видимый справа. Скажите «Астра, замуть участника два». При включённом подтверждении дождитесь ответа и скажите «Астра, подтверди участника два»; при выключенном действие выполняется сразу. Номера сохраняются до переподключения бота; выбор и подтверждение действуют минуту и только для аккаунта, который отдал команду.

    Кнопка «Голосовое имя» в списке участников добавит ID. Укажите простое русское имя и его формы через запятую. Если имя не совпало или совпадений несколько, скажите «Астра, выбери участника два». Подтвердите номер, если подтверждение включено; иначе действие выполнится после выбора. Приблизительное звучание не запускает действие.

    Перенос: «Астра, перемести Сашу в канал три» или «Астра, перемести участника два в Игровую». При включённом подтверждении бот повторит канал назначения и попросит подтвердить номер участника.
